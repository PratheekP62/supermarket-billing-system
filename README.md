# Supermarket Billing System (C++)

## Description
A console-based C++ application that manages supermarket billing operations including product selection, billing calculation, and invoice generation.

## Tech Stack
- C++
- File Handling / OOP

## Features
- Product Management
- Add to Cart
- Bill Calculation
- Discount Calculation
- Invoice Generation

## How to Run
1. Compile using g++
2. Run executable file
3. Follow console instructions
